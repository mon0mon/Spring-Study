= Introduction

HTTP 프로토콜은 요청-응답 프로토콜
클라이언트가 서버에 HTTP 요청을 보내면 서버는 요청 없으면 응답 불가
HTTP가 분산 하이퍼미디어 시스템에서 리소스 전송 목적으로 개발됨
따라서 HTTP는 동시에 양방향 통신 미지원

이 한계 극복을 위해 여러 HTTP 메커니즘 등장
비공식적으로 Comet이라 칭함
종종 복잡·비효율적

웹소켓 프로토콜은 기존 HTTP 메커니즘 대체
브라우저와 서버 간 저지연·양방향 통신 효과적 수단
단일 TCP 연결 통한 데이터 전송 효율 향상
